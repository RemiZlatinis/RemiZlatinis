## What I bring

- **Systems thinking:** I turn ambiguous requirements into maintainable architectures, explicit boundaries, and software that remains understandable as it grows.
- **End-to-end ownership:** I am comfortable taking a product from infrastructure and backend design through real-time data flows, web UX, mobile delivery, and documentation.
- **Engineering judgment:** I care about type safety, secure authentication, source-of-truth boundaries, operational simplicity, and the quality of the developer experience.

## Infrastructure & DevOps

I bring an operations-first perspective to software engineering. Years of system administration, homelab work, and hands-on experience hosting applications on-premises have given me a deep understanding of the environment software must actually run in — not just the code that builds it.

- **Linux server administration:** provisioning, hardening, networking, service management, reverse proxies, storage, backups, and troubleshooting.
- **Delivery and operations:** containerized workloads, environment management, deployment automation, monitoring, logs, and the practical path from a local change to a dependable production service.
- **Developer productivity:** reproducible setups, clear operational documentation, automation, and tooling that reduces avoidable friction for the whole team.

That background lets me connect application architecture with infrastructure realities: designing systems that are observable, recoverable, secure, and straightforward to operate.

## Selected work

### [Service Status Indicator](https://www.service-status-indicator.com/) · Open-source monitoring platform

My flagship project: a complete monitoring ecosystem that turns ordinary Bash scripts into a real-time status feed.

- Designed the system as separate **Linux agent, Django backend, and web/mobile client** components.
- Built a systemd-native agent with scheduled execution, script validation, low overhead, and persistent real-time reporting.
- Implemented the backend as the authoritative source of truth for agent registration, authentication, service state, APIs, and live updates.
- Delivered one Expo client across **Android, iOS, and Web**, with secure sessions, Google Sign-In, WebSocket/SSE real-time updates, and native push notifications.
- Built the product website and documentation portal with build-time documentation ingestion, syntax highlighting, and Mermaid architecture diagrams.

This is the kind of project I enjoy most: a real product with infrastructure, distributed boundaries, multiple clients, and enough complexity to reward careful engineering.

### [Game Hub](https://game-hub-remizlatinis.vercel.app/) · Web product

A simple, focused web application demonstrating responsive product UI, client-side state, API integration, and the discipline required to keep a user-facing application fast and understandable.

### [Management System](https://e1-status-app-prototype.vercel.app/) · Application prototype

A business automation system for accounting offices that turns complex, repetitive work into a streamlined workflow completed in a few clicks. Behind the simple interface, an automation engine removes hundreds of hours of manual work each month and significantly reduces the human errors that can lead to costly financial damage — giving office owners back time, confidence, and peace of mind.

### [Portfolio website](https://ioannisvarelidis.remiservices.uk/) · Client delivery

A polished portfolio experience built to present a professional identity clearly, with attention to information hierarchy, responsive behavior, and the details that make a small product feel finished.
